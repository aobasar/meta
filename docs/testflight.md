## Beta description

Kokobubu shows you how to use a physical device. Point your iPhone at a washing machine, a remote or a control panel,
and say what you want to do in Turkish or English. It reads the labels, marks the right control through the camera,
and guides you one step at a time. After each step it looks again and tells you if the step isn't right yet.

This is an experimental prototype. Guidance is generated by AI and can be wrong: check before you press. Labels and
manuals come first. It is not for gas, electrical panels, vehicles or medication. For adults, 18 and up.

## What to test

1. Enter your invite code and allow the camera and the microphone.
2. Point the camera at a device you have, such as a microwave, a remote or a washing machine.
3. Tap the microphone and say what you want to do, or type it.
4. Follow the marker, do the step yourself, then tap "I've done it".
5. Try doing a step wrong on purpose, and see whether Kokobubu notices.
6. Try a simple task without opening the device's manual.

Tell us what went wrong, and on which device. Don't film other people.

### Review notes

Kokobubu is an AR guide for physical devices. It needs a real iPhone with a camera: ARKit doesn't run in the simulator.
LiDAR improves the marker but isn't required. Any everyday device works for the test, such as a microwave or a TV remote.

Enter the invite code on the first screen. Then accept the consent screen, point the camera at a device, tap the
microphone and ask, for example, "How do I set the clock?". A marker shows which control to touch. The user presses it,
then taps "I've done it", and the app checks the step in a new photo.

The app takes no action on any device: the user does every step. Frames, audio and typed words go to the developer's
server (kokobubu-api.aobasar.com), which passes them to Meta's AI models through the Meta Model API. The consent screen
says this before anything leaves the phone. The API key stays on the server. The server refuses requests from Meta's
Restricted Territories, so the app shows an error there.

## Export compliance

The app uses only standard HTTPS. `ITSAppUsesNonExemptEncryption` is `false` in the build, so App Store Connect doesn't ask.
